## Bug Bounty Report Template

This repository also contains bug bounty report templates that can help in writing clean and professional vulnerability reports.

A good bug bounty report should include:

* Vulnerability title
* Severity
* Bug type
* Affected asset
* Steps to reproduce
* Impact
* Proof of Concept
* Suggested fix
* References
* CVSS score, if applicable

This repository is strictly for educational and authorized security learning only.
